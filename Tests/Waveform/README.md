# 波形服务主机验证

执行 `python Tests/Waveform/run_tests.py`。仅使用主机 GCC，产物写入忽略的
`Logs/Waveform/`；不访问硬件。

本阶段实现 **20 ms 共同窗口**（48 kHz 名义 960 点）和 **10 Hz** 计划节流。
A 生成共同时间窗口计划，B 严格采用 A 的绝对时间窗，但两板分别用本板
`AudioTimeMap` 把该时间窗映射到自己的 DMA 帧；不按相同 DMA 帧号取数，不移动
原始 PCM，不做独立过零对齐或相位补偿。无共同计划、未同步或模型失效时，B 显示
本板最近原始 PCM 并标 `LOCAL / UNSYNCED`；已知最近共同 `PERIOD` 周期时沿用该周期
显示约 3 个周期，否则回退 20 ms；无有效采样显示 `NO DATA`，不画人工零线。周期跟踪仅由 A 做一次相位参考锁存，之后按整数周期网格生成 `PERIOD`
窗口；候选每200ms检查，连续3次在首候选±0.5%内才建立或修订周期；短暂失败保留
最后可靠PCM周期证据至600ms（等待、失败和发计划均不续期），到期回 `RAW`。
非周期信号也走共同固定窗。`PERIOD` 窗口按约 3 个
周期缩短跨度（1 ms..20 ms 限幅），便于观察两板相位；`RAW` 保持固定 20 ms。

WVP2 固定 56 字节，大端逐字段序列化，禁止发送 C 结构体：
0..3 魔数 `WVP2`，4..7 域，8..11 权威代际，12..15 序列，16 模式（RAW/PERIOD），
17 标志，18..19 保留全零，20..27 计划共同时间，28..35 窗口起点，36..43 窗口
跨度，44..47 周期毫赫兹（RAW 为 0），48..55 显示 deadline。WVP1 44 字节已废弃，
旧 B 端拒绝 WVP2、新 B 端拒绝 WVP1，A/B 必须使用配套镜像。

窗口时间定义：`window_end = plan_common - HISTORY_DELAY`，
`window_start = window_end - span`，`display_deadline = plan_common + DISPLAY_LEAD`。
当前初始值 350 ms / 100 ms 只是设计初值，必须实机测量音频环可用性、网络/渲染
耗时后调整；deadline 实际参与 A 发布和 B 接收调度。20 ms/10 Hz 只覆盖约 20% 时间，
10 ms 级脉冲可能漏看；接口参数化为后续 100 ms 环境模式预留，但本阶段不启用。

周期检测使用2048帧和最大480帧滞后邻域。过零提议先验证差分重复性和2/3/4/5分频
候选，失败才扫描8..480帧；一次扫描缓存误差，选择 `E<=min(0.08,best+0.02)` 的
最短局部谷，避免分数周期的整数倍滞后替代基周期。分数拟合仅用于周期元数据。
持续1%真实频变也经过3次确认后修订，以旧网格邻近历史窗的时间标记连续衔接，
不重新跟随A移动后的过零点；B不作周期搜索或相位对齐。三次确认最多约600ms
是分析候选的响应，不含350ms历史、100ms显示deadline和前台调度延迟。

A的LOCAL尺度按可靠PCM检测计龄；B的LOCAL尺度按最近接收A的PERIOD计划计龄，
两者都仅保留600ms。WVP2不携带A最后可靠检测时间，A保持期间的计划可能给B续期，
故断网时B的旧尺度最坏比A晚约600ms到期。RAW计划立即清尺度，重复包不续期；
断流、音频会话或共同域改变清尺度；时钟模型重建只可暂留未过期尺度，仍标LOCAL。
迟包余量保持250ms，且渲染仍检查实际PCM历史：32768帧约683ms，迟包被接受
并不代表窗口仍在历史内；窗口覆盖、650ms计划过期或1.5s模型过期均须退LOCAL。

`WaveformSnapshot`的candidate_milli_hz/confirmation_count/reason说明最近候选和
资格原因；period_age_ms为A的PCM证据年龄或B的计划接收年龄，无证据为UINT32_MAX。
原因数值见 `waveform_service.h` 的WaveformReason枚举，不编码进WVP2。

横轴是 PTP 模型时间，**不等于硬件采样时钟同步**：两板 SAI 各自使用
本板 PLLI2S，PTP/PPS 不驯服采样时钟；`AudioTimeMap` 只做软件帧到共同时间映射，
不覆盖 codec/SAI/FIFO 延迟和跨板采样起点误差。界面只做显示映射：960 点按屏幕
宽度取每像素 Min/Max 包络，固定满量程 PCM，不滤波、不平滑、不插值、不修改 PCM。
统一固定幅度需先在实机确认两板麦克风增益与噪声底；自动缩放默认关闭。

测试覆盖：Init 前不访问、断流、真实 End 失败、本地原始回退、LOCAL 沿用最近
周期约 3 周期、RAW 共同窗、PERIOD 相位网格、500 Hz 与 1882.35 Hz 分数周期、跨计划整数周期、B 跟随共同
窗口、换域/旧包拒绝、WVP2 长度与保留字段、10 Hz 节流、计划 deadline、Min/Max
固定幅度和真实 AudioCapture 集成；runner 同时执行 O0/O2 核心目标。
新增回归覆盖三候选、2/4/5倍整数滞后、600ms到期、相位改变不重对齐、1%频变、
RAW/跨域撤旧尺度、连续推进历史下的迟包覆盖，以及噪声/尖峰逐点原始PCM保真。
Min/Max界面检查由 `Tests/TouchGFXView/run_tests.py` 单独执行。

实机跨板相位稳定性、长期漂移、1 kHz ±2 % 周期、10 Hz 下音频丢块和 deadline
余量仍须统一上板验收；主机测试只证明软件路径，不代表实物精度通过。
