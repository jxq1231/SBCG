# 波形服务主机验证

执行 `python Tests/Waveform/run_tests.py`。仅使用主机 GCC，产物写入忽略的
`Logs/Waveform/`；不访问硬件。

覆盖真实借用复制、End失败、断流、跨块500 Hz、自相关无周期降级、双方共同窗、
B相移保留、旧域拒绝、重复包不续期、长度检查。生产代码静态断言限制历史环和
stage合计小于128 KiB；当前为81920字节，全部在`.WaveformState`。增加初始化前
非法借用指针不读取、范围端点50Hz/2kHz、4kHz不误报二倍周期、退帧/最大值锚点
拒绝，以及前台延迟后先发布到期计划再生成下一计划的回归覆盖。

集成调用顺序：仅SDRAM成功就绪后Init；未Init时Stage/Complete/Update/Observe
均不操作，避免外部存储故障影响其他音频业务。唯一音频Begin之后StageBlock；原有End之后将
真实返回值交给CompleteBlock；现有锚点单消费者取得观测后扇出ObserveAnchor；
前台Update最新共同读时/健康/会话，随后分派接收计划并发送TakePlan。界面只读
WaveformSnapshot，frame_seq变化才更新，采集与页面切换无关。

WVP1固定44字节，大端无符号：0..3魔数，4..7域，8..11权威代际，12..15序号，
16..23显示deadline纳秒，24..31共同窗起点纳秒，32..35跨度纳秒，36..39周期毫赫兹
（0代表固定窗），40..43保留全零。仅复用已验证对端的UDP 5005端点，不新建PCB。

`synced`表示具备会话资格、两锚点模型和A共同窗，不证明声学同步精度。
1 Hz锚点经既有AudioTimeMap检查后，中点线性模型最多延用1.5秒以支持5 Hz显示。
PCM零基帧n对应NDTR进度n+1；模型不补偿编解码器/SAI/FIFO延迟。A在350 ms历史点
附近寻找参考过零，100 ms后双方按共同deadline发布，目标每200 ms更新。
B严格采用共同起点，不独立触发相位；无周期使用10 ms共同固定窗；失域、无模型
或计划超时使用本地自由运行真PCM并撤销synced；断流则valid=false。

自相关搜索范围24..960帧，适合约50 Hz至2 kHz的单一主周期；超范围、谐波或
噪声可能无法确定基频，界面周期只作观察。横轴是PTP模型时间，points为PCM16
固定满幅；无自动增益，不用于独立TDOA计算。实机跨板相位、处理耗时和网络到达
deadline的效果仍须统一上板验收。

参考过零由A使用邻近两点线性插值，双方绘图也对CPU历史相邻两点线性插值，
避免2kHz时整帧取整带来的约4.17%周期台阶；B仍完全采用A的共同起点。
测试覆盖2kHz及997Hz、四种块首帧偏移/初相位、每组五个连续计划，并验证B两种
移动相移。解析波形及连续帧差异门限1400 PCM，对12000幅值正弦小于2%周期
最大斜率对应的约1508 PCM；这是确定性软件用例，并非实机同步精度保证。
runner同时运行O0/O2的核心及真实AudioCapture集成目标。

时钟所有者须在PTP跳变或连续调频动作前调用`WaveformService_NotifyClockChange()`。
该边界撤销旧模型、锚点、计划及SYNCED，保留与时间域独立的PCM环用于LOCAL；
边界后重新收到两个有效锚点才能恢复模型，禁止将调频前后的锚点拼成同一斜率。
共同代际切换也撤销模型/计划；PCM环保留不代表旧域资格恢复，新的source_floor
及新锚点对决定可用共同窗口。无新计划650 ms后撤销SYNCED并回本地波形。
