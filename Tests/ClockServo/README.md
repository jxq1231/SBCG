# ClockServo 真实纯 C 测试

运行 `python Tests/ClockServo/run_tests.py`。沿现有主机测试方式，以 Native GCC
编译真实 `App/Sync/clock_servo.c`，开启 `-O2 -Wall -Wextra -Werror`。
可执行文件位于忽略的 `Logs/TimeSync/M2_3_2/`，不替换控制器、不访问板卡。

## 控制及符号

- `offset_x2_ns` 为 B−A 的两倍纳秒，保存半纳秒分子；正偏差需要负相位/负频率。
- `frequency_ppb` 是硬件相对标称值的**绝对**频率，仅成功 Commit 后更新。
- 至少三个相邻差值不超过 250us 的合格样本后，绝对偏差超过 1ms 才允许
  STEP。成功覆盖后重新积累窗口。后续单个大偏差只重启获取，不能立即跳时。
- 每个恒定已应用频率分段使用至少一秒的 A 参考历时估计残余漂移：
  `drift_ppb = (offset_now_ns - offset_anchor_ns) * 1e9 / reference_elapsed_ns`。
  变频提交后由下一个样本建立新锚点，不跨频率分段计算斜率。
- 获取时目标为 `f_new = f_applied - residual_drift_ppb - offset_ns/2`，
  两秒相位时间常数，更新间隔至少一秒，目标限幅 ±100000ppb。
- 锁定后在合格范围内保持频率至少八秒，更新采用十六秒相位时间常数。
  将获取时的两秒增益直接用于八秒间隔会引起离散振荡，因此分段使用增益。
  每次实际变频后清除锁定证据，用新分段重新满足锁定要求。
- 连续八个有效样本同时满足 `|offset_x2_ns| <= 20000`、已有真实漂移窗口、
  `|drift_ppb| <= 500` 和 `delay_x2_ns <= 4000000`，才能报告内部锁。
  锁定门槛直接比较两倍纳秒，避免 10000.5ns 截断后误通过。
- 2秒无合格样本转 HOLDOVER，撤锁并清除历史；5秒转 UNSYNCED。
  两者保持已确认频率。重新获取必须重新积累样本。
- 上层质量校验拒绝使用 `ClockServo_RejectMeasurement`，它增加拒绝计数、
  撤锁/清历史并保留最后有效样本时刻。持续坏包不能推迟2秒/5秒状态。
  `Invalidate` 仍只用于对端重启/时钟代际失效，显式重新开始获取计时。
- 每次请求必须在同一前台周期执行，Observe 后100ms内 Commit；失败、
  错配或过期提交进入 FAULT，必须外部明确恢复到标称频率后 Init。
  在待确认动作仍存在时 Invalidate/超时也进入 FAULT，不假定回滚。
- 首次标称频率可用 `ClockServo_Init`；软件重新初始化时用
  `ClockServo_InitKnown` 采用新鲜BSP读回的实际ppb，保留已有硬件校正。
  该接口验证±100000ppb范围，越界进入FAULT，不静默恢复成0ppb。

## 输入边界与责任

调用方先验证四时刻配对、代际、来源及每个时钟域内交换不超过100ms。
Servo 没有四时刻输入，不能替代交换窗口校验。它检查平均路径时延0～2ms、
A时刻范围/单调性、相邻参考历时不超过2秒，以及参考历时与本地毫秒历时
差不超过100ms。异常参考重新获取，路径异常中断连续锁定证据。
所有接口只用于单个前台调用者；不在IRQ执行硬件动作。

## 测试证据与局限

仿真每250ms积分 B−A 相位，频率只由实际生成且成功提交的动作更新。
积分按整数纳秒截断；误差每步小于1ns。固定种子均匀测量抖动 ±100ns，
覆盖初始 +3秒、−2秒、0、±999999ns 与自然漂移 ±50000ppb 的十个组合。
检查30秒内首次内部锁、30～60秒实际相位在±10us内、内部锁的证据、
多数后段样本仍锁定、频率修正方向/限幅，以及至少3秒稳定频率窗口。

独立案例覆盖三样本引导、正负STEP、成功提交前状态、频率/相位失败、
伪造提交、2/5秒丢包状态、短时丢包、延迟离群、单个相位离群、参考倒退/
跳变、uint32毫秒回绕/倒退、INT64/UINT64边界、NULL和半纳秒门槛。
额外覆盖实际非零频率重新初始化、越界初始化、动作过期/错配/空确认，
以及动作尚未确认时的Invalidate/超时故障。
质量拒绝回归覆盖已锁后每250ms拒绝持续5.5秒、毫秒回绕、最后有效样本
时刻不变、非零实际频率保持、重新收到正常样本后的完整重新获取，
以及存在待确认动作时质量拒绝转FAULT且不会被后续拒绝解除。

这仅验证数学控制、有限状态和接口约定。实际网络抖动、路径非对称、
MAC命令延迟及硬件方向仍需板端验证；内部锁不等同外部±10us验收。
