## 资料如何使用

- **课程要求**：来自《嵌入式系统课程设计—分布式声波测距系统—设计任务书（V1.0）》，页码及验收指标集中在路线文档。评分或测试口径不明确的地方原样标注，不擅自改成新要求。
- **当前状态**：只在Project_State中集中维护；构建通过、烧录校验通过、实物运行通过分别记录。
- **技术方案**：RGB565、ETH/PTP、TIM2 PPS、UID角色及共享温度等属于本项目设计选择，不是任务书指定的唯一实现。
- **后续参数**：硬件资源表中的FMC/LTDC/ETH/SAI等是配置目标，当前未启用；实施时须通过CubeMX生成并逐项验收。
- **历史证据**：Milestones保存实际发生的实验。旧固件的地址、哈希与观察值不能直接作为新固件的证明。
