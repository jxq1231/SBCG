# 双板声学测距稳定化与编码声包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 根目录AGENTS.md和用户当前指令优先；本文件不是烧录、CubeMX操作或后续阶段的自动授权。

**Goal:** 在现有硬件与已验证PTP/PPS基础上，实现可信距离稳定跟踪、真实移动后连续确认更新；只有当前声学链证据不足时才切换编码声包路线。

**Architecture:** A板对独立发声的有符号TDOA进行质量审查、稳健跟踪和温补，发布唯一结果与状态，B按同一ID/状态显示。检测、测量有效性和上次结果展示分开；声包同步与PTP时间同步分开。

**Tech Stack:** STM32F746、CubeMX HAL、SAI2 DMA、C11、LwIP UDP、TouchGFX、CMake Debug/Release、Python离线回放。

## 绝对边界

- 本次计划不重写同步伺服、RCC、GPIO、DMA、NVIC、SAI、ETH、LTDC/FMC、HAL或生成配置。不手改`.ioc`和`LWIP/Target/lwipopts.h`。
- 已有PPS示波器10次记录保留，不安排复测；新固件只做同步状态与故障计数回归，不能把它称作新一轮外部精度验收。
- 当前工作区未提交的稳定器、临时显示、音频WAV/清单与测试全部视为用户自有基线；LICENSE删除、`nul`和交接文档不混入功能提交。
- 不push/amend/rebase/reset/clean。每个已验证独立增量定向提交，作者与提交者jxq；未实机验证的功能不得记为硬件完成。
- 不将320mm真值硬编码成测量输出、不钳位错误值到真值、不靠冻结重复显示凑10次标准差。
- 不降低现有0.80模板门限来宣称身份识别通过；不同检测评分单独命名、单独资格评估。
- CLAP、单点标定入口、5m/10m扩展、同步波形显示是后续独立目标，本包不一并实现。
- 用户曾明确要求不改测量时间契约；交接文档又将“2秒”解释为首声时限。先保持既有合同，G0列明“按钮播放/实际首声/标准包确认”的不同起点，请用户决定正式口径；在此之前只报告各延迟，不自动新增或删除时限要求。

## 决策主线

```text
G0固定镜像/WAV/真值/日志口径
  → O1被动元数据/观测/全槽分析与分板接收
  → A1纯跟踪器（2秒节奏、拒绝不清窗、确认新簇）
  → A2显式状态/年龄/ID经A权威发布到B
  → A3当前50ms单chirp双板验证
       ├─ 原始TOA稳定、显示仍不稳：只修状态/协议，不换声
       ├─ 某层缺事件：按逐槽账本修该层，不泛调门限
       ├─ 约200µs路径切换/身份误判：O2补连续PCM→A4离线对比检测
       └─ 经过受限对比仍不能兼顾身份/精度/设备适配：进入B声包
  → 基础0.20～2.00m矩阵 → 后续提高项另立计划
```

不得把所有阶段交给多个agent同时修改。允许并行只读核验、纯模块独立测试设计；`App/app_main.c`、协议、共享头文件与硬件由单一集成者串行处理。
