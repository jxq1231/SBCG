# 分类器/TOA 实验思路记录（2026-11-07）

> **状态声明：以下全部是未验证的历史实验思路，没有任何一组经过有效性与精度验收。**
> 当前固件已回到最早的已提交分类器基线，以下思路不参与构建、不作为设计依据。
> 记录目的仅是后续采集更多数据后做对照实验；**不要被这些思路限制**，允许全部推翻。

## 1. 背景

问题集中在“带混响/长尾的击掌”和“击掌前沿选择”：

- 击掌经房间反射后活动段很长，旧的 `active <= CLAP_MAX_ACTIVE_FRAMES` 会把它判成 UNKNOWN；
- 拍掌是单次陡前沿，而通用后向/连续前沿估计器可能选到后续反射边沿；
- 两板波形互相关在混响下可能出现载波周期滑移，选到相邻竞争峰。

## 2. 思路 A：90% 能量主段（原 C1）

- 在全窗计算平方能量，取累计能量 5% 与 95% 分位之间的帧跨度 `energy_span_frames`；
- 击掌短瞬态判据改为 `energy_span_frames <= 1440` 帧（48 kHz 下 30 ms），替代整段活动长度；
- 预期：零散混响尾不拉长主段，长尾击掌仍可判 CLAP。

**未验证风险**：能量分位对噪声底、AGC、截断窗敏感；低信噪比时 5% 分位可能落在噪声上；与扫频的能量分布差异未测。

## 3. 思路 B：拍掌专用 TOA（原 C2）

- 在候选的 256 帧窗仍可得时，同时计算两套 TOA：
  - 原连续/后向前沿（`ToaBackward_DefaultConfig`）；
  - 拍掌单阈值前沿（128 LSB、峰值 1/8）。
- 分类完成后按类型交接：CLAP 用单阈值结果，其他用原结果；
- 配套诊断：`$CLAP_EVENT,PATH=TX/RX,...`、`$SOUND_PAIR` 增加 `TYPE/A_NS/B_NS/DOMAIN/QUALITY`。

**未验证风险**：固定 128 LSB 阈值受距离/增益影响；强反射可能仍先过阈；两套 TOA 的额外前台耗时未测；诊断字段对串口带宽的影响未测。

## 4. 思路 C：半峰值主脉冲（原 B1）

- 若整段活动很长，再检查“半峰值以上样本的首末跨度”；
- 主脉冲跨度 ≤ `CLAP_MAX_ACTIVE_FRAMES` 时仍判 CLAP；
- 与思路 A 是**竞争方案**，不是叠加关系。

**未验证风险**：半峰值阈值对双峰/多径击掌敏感；远处二次脉冲可能被计入跨度；与 A 的误判率对比未做。

## 5. 思路 D：包络相关竞争峰复核（原 B2）

- 载波互相关找到峰后，检查间隔 ≥6 样本、相关度差 <0.02 的竞争峰；
- 用 21 点绝对幅值包络相关复核，决定是否更换所选峰；
- 预期抑制混响下的 ±1 载波周期滑移。

**未验证风险**：21 点包络平滑会削弱近距双峰分辨力；额外计算量未上板测；竞争峰门限（0.02/6）无数据支撑。

## 6. 后续数据与评估建议

1. 采集带标签数据集：不同距离/角度、强混响与消声、单掌/多掌、标准 chirp、纯音、噪声；
2. 分类评估：混淆矩阵、CLAP 漏检/误检率、UNKNOWN 比例，按房间/距离分组；
3. TOA 评估：与人工标注前沿对比的偏差分布、离群率；
4. TDOA 评估：与几何真值/高精度参考对比，统计 ±1 周期滑移率；
5. 调参集与验证集分开；任何门限必须用未参与调参的数据复验；
6. 上述任一思路在数据上不成立时应直接放弃，不要为了保留实现而迁就结论。
