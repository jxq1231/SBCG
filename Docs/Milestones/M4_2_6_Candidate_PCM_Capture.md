## 实物验收（待烧录授权，未执行）

1. 烧录 Debug `SBCG-M4.2-PCMCAP` 至 A 板（openocd program+verify，受控reset）。
2. PC 固定 192.168.10.100，先启动 `udp_chirp_capture.py --out Logs/Chirp/PCM/<trial> --tag dist=..;vol=..;dir=..`。
3. 原接线、同一 `standard_chirp_2-6khz_10x_20s.wav` 20秒/一次，记录串口 `$CHIRP_SEARCH`/`$CHIRP_CAPTURE`。
4. 核对：每完成任务恰好一包PCM、`$CHIRP_CAPTURE` 与 `$CHIRP_SEARCH` 按 (SESSION,ID) 对账、PKTS==TOTAL、资源/跳过错误计数 0。
5. 离线：`chirp_capture_analysis.py --captures <trial> --template chirp_2-6khz_50ms_template.wav --out out.json`，对比宽带峰/带限峰/0.80、`lag_shift`，读取负样本FA曲线。
6. 受控重复（距离/音量/方向各≥5次）后聚合 CORR_PPM 分布与负样本，确定能否把“门限过严”与“声学失真/多径”分开；只有负样本证明放宽后误报可接受才讨论门限，不在本里程碑改0.80。

## 自动试跑实物结果（2026-10-26，A板，链路UP）

使用 `run_pcm_trial.py`（串口+UDP 6008 同时采集、winsound 自动播放同一20s WAV）完成两轮自检。

- `auto-20261026-01`（默认音量）：在线 raw 峰 CORR_PPM 56518–91358、RMS 90–104，几乎无有效声学激励（声耦合不足），仅证明管线闭环。
- `auto-20261026-02`（wave 主音量确认为100%后复跑）：3 个响任务 id 114/115/116 + 1 个背景任务 id124。
  - **在线≈离线**：离线全对齐宽带峰与在线 CORR_PPM 完全一致（0.588241/0.574080/0.581004，shift=0）——捕获切片与评分窗口是同一数据，capture+offline 管线按戳到万分位，无对齐/内容错位。
  - **2–6kHz 带限≈宽带**（0.573–0.588 vs 0.581–0.588）——带外噪声不是相关不足的原因。
  - **带内失配集中在 chirp 尾部**：头半段相关 0.670–0.724 显著高于尾半段 0.430–0.489；峰宽度窄（±2帧补偿相关骤降至0.18–0.42）——不是对齐/搜索问题，指向扬声器/麦克风高频端（chirp 末端2–6k高频）的频响滚降或末端失真。
  - **能量健康**：RMS 2465–2493、CLIP=0 —— 不是弱信号或门控漏检。
  - **负样本干净**：4个捕获 106 个静音窗最大相关 0.055–0.097，n≥0.55 为 0——当前背景无门限风险，但对“非本chirp声事件”的误报仍未覆盖，按约定不改0.80。

- `auto-20261026-03`（扬声器贴近麦克风，vol=100）：id 170/171/172 三个响任务。
  - **相关回升**：全段 0.6917/0.6923/0.6962（对比 −02 的 0.574–0.588）；头/尾半段 **0.69–0.71 与 0.68–0.71 基本持平**——−02 的“尾半段失配”(0.43–0.49)消失，证明高频端滚降是距离相关的近场/房间效应。
  - 峰仍窄（±2帧降至 0.28–0.37）、shift=0、带限≈宽带、负样本 79 窗最大 0.076——对齐/带外/背景因素依旧排除。
  - **残余差距 0.69–0.70 vs 0.80 约 0.10–0.11**，且头尾已均衡 → 指向换能器/麦克风全带的幅相着色或近场大声压失真，而非端点滚降；下一步做受控音量阶梯（60/80/100%）找失真拐点与最佳点。

结论：M4.2.5 以来同型失败（真实chirp相关 0.57–0.77 < 0.80）在本轮被 CD 级区分：非门限/对齐/带外/预算，而是**带内声学路径的高频端波形失配**。下一步优先物理改善耦合与频响（扬声器/位置），或评估对模板做高频/末端容差，同时继续收集受控音量/距离/方向的分布与更广负样本。

## 已知限制

- 捕获内容为模板幅度级（±2048窗外静音）；UDP 发送不重试，RESULT 只表示栈接受。
- 左/右裁剪在 CLAMP/左/右标志与 TAIL 中如实上报；离线分析自动以实际跨度为本。
- 本里程碑不证明 PTP 时间、物理到达精度、双板配对或测距通过。
