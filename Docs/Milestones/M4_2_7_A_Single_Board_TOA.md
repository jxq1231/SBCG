# M4.2.7-A 单板声事件到达时刻（TOA）子帧估算

<!-- doc-status: experimental-toa-not-accuracy-accepted; reviewed: 2026-10-26 -->

> 最新目标复核：TOA-A/B均有实物输出，但标准CHIRP匹配仍0，整体±100μs未验收。部分slot的跨轮离均值稳定不能代表到达精度；B09额外背景候选被归入slot9，完整报告仍FAIL。TOA_US当前是名义48000Hz采样轴，不是PTP时间。下文保留对应实验范围；纠正口径及后续顺序见[目标路线](../Goal_Aligned_Roadmap_2026_10_26.md)。工作区另有未提交B2算法，不把它当已实测。

## 目标

在不依赖波形模板匹配的前提下，为已验证的能量候选输出本板计时基准的声到达时刻（帧+前沿子帧插值，单位 μs），支撑任务书基础(2)「同一位置重复播放，相邻两次到达时刻差 ≤±100μs」的单板验收。不改变 0.80 相关门限、不做识别达标承诺。

## 实现

- `App/Detector/toa_estimator.c/.h`：纯C轻松估算。取候选窗绝对幅值峰值，实际阈值=max(配置阈值, 峰值/relative_scale)，扫描首个自下而上过阈样本对，线性插值出子帧位置；窗口8..512点。
- `App/Detector/sound_detector_service.c/.h`：Stage 借用期内取 onset 起 32 帧做估算，存入队列项；Process 发布 `$SOUND_CAND` 时追加 `TOA_US`（帧坐标+插值分数 → μs，无效为 `NA`）；快照增 `toa_ok/toa_miss`。
- `cmake/audio-layout.cmake`：注册 toa_estimator.c；三个测试运行器对应补源。

## 验证（软件）

- `Tests/Detector/test_toa_estimator.c` O0/O2：整数/分数前沿、相对阈值自适应、首样本过阈/全零/恒压拒绝、参数非法不改输出，全过。
- `Tests/SoundDetectorService/test_service.c`：新增确定斜坡用例，断言 `TOA_US=231` 与计数；既有 7 组 + 批量逐字段 + 其余服务/音频/Chirp/App 回归全过。
- Debug/Release 构建 GREEN，check_audio/check_eth 两配置 PASS；仅改前台计算与串口行，无新 IRQ/DMA/CubeMX。

## 待实物

- 烧录新镜像后再做：固定位置重复播放 N 次，串口对每次 `$SOUND_CAND` 的 `TOA_US` 计算相邻差最大偏差与 σ vs ±100μs；静默 60s 无 `TOA_US` 输出（基础(4)）。允许诊断期继续不识别，不调 0.80。

## 实物结果（2026-10-26，3 轮近场重复播放）

- 管线各环成立：SOUND_CAND 每 chirp 有 TOA_US（与 FIRST 帧换算一致）；驱动改为 SND_ASYNC 后串口全程不漏（905/894/907 行）；分析器用**板内 TOA 间隔整数倍**对齐槽位（0 播放前瞬态 + slot0 公共时延去宿主启动抖动），三轮全部 slot0..9 出数。
- **未达标观测，尚非唯一根因定位**：初版窗口受64帧门控栅格影响；逐chirp间隔与逐槽跨轮偏差提示需检查窗口/选峰。slot7跨轮离均值偏差88μs仅是单槽现象，不能据此证明相邻检测或整体±100μs；源端/采样时钟比例项也需分离。
- 结论：子帧插值本身正确，**±100μs 需要改为与门控栅格无关的前沿估计**（如起跳能量包络+回溯/更长候选窗锚定绝对前沿）——记入 M4.2.7-B，本增量不触碰 0.80 门限与识别参数。

## 限制

- TOA_US 为帧栅格 20.8μs×子帧插值，受波形斜率/反射影响，其精度以实测抖动为准，不承诺绝对声学时刻。
- 本里程碑不涉及两板 PTP 域换算（由后续 SoundEventTime 锚点复用/双板阶段完成）与测距/方向显示（下一步 M4.2.7-B）。

## M4.2.7-B 峰回溯栅格无关估计（实物复验 2026-10-26）

- 新增 `ToaEstimator_EstimateBackward`：窗内峰值向左找最后一段连续4样本过阈起点并线性插值；服务改用锚点=onset−64、256帧窗，队列记录锚点绝对帧。
- 软件侧：估算器回测用例（斜坡28.65、尖峰拒绝、整窗拒绝、参数非法）+ 服务 `TOA_US=188` 用例全过；Debug 构建/布局 GREEN。
- 实物3轮：slots3/4/7/8在“各轮减slot0、同槽跨轮离均值”统计中偏差0.7–14.7μs、σ≤10.4μs，仅证明部分相对槽位稳定，**不是±100μs到达验收**；slots1/2/5/6仍约1.8–2.1ms。slot9含额外背景候选，n=4、最大离均值偏差421429.5μs，总报告FAIL_OR_INSUFFICIENT，不能漏报或无记录删去。
- 全10个明显播放响应的相邻名义2s间隔残差，三轮最大绝对值3727/3288/3289μs，仍混合源端/采样时钟和检测误差。峰回溯并不保证最早直达前沿，波瓣切换、窗口变化、反射均是待验证因素，不能唯一确诊多径。下一步先做边界安全与全事件回放对账，再比较B2能量包络等具体策略，不只挑稳定slot或继续相同条件盲测。
