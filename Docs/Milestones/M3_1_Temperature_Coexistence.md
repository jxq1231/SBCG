## 实验步骤与实际响应

通过既有COM3、1152008N1、DTR/RTS关闭发送命令，逐条等待响应，保护原始记录。
开始先查询，确认AUTO/DHT11/VALID=1后才切换；失败清理流程会尝试恢复AUTO并确认。
实际20条命令全部完成预期检查，串口接收错误/溢出/重装错误均为0。

| 阶段 | 实测结果 |
| --- | --- |
| 初始TEMP?与PING | 自动有效；PING返回OK |
| TEMP SET 25.0 | MANUAL/VALID=1，25000毫摄氏度，346450mm/s，版本43 |
| 保持并TEMP? | 持续17.256秒，超过自动样本15秒过期界限；值和版本43保持有效，未被传感器覆盖 |
| TEMP SET 0 | 有效零温，0毫摄氏度、331300mm/s，版本44；查询保持 |
| TEMP SET -10.0 | 有效负温，-10000毫摄氏度、325240mm/s，版本45；查询保持 |
| 61.0、-20.1、nan、25.00 | 四条SET均ERROR/REASON=VALUE；每次随后查询，原负温和值/版本45均不变 |
| 首次TEMP AUTO | AUTO/NONE/VALID=0，保留版本45，省略旧手动温度/声速/年龄字段 |
| 自动恢复 | 捕获5条周期UNREADY，再在AUTO发送后约5.459秒首次周期观测OK/版本46；这是输出观测延迟，不是精密采集时间 |
| 恢复查询 | AUTO/DHT11/VALID=1，版本47；再次AUTO保持自动有效，没有重新失效 |
| 结束状态 | AUTO/DHT11/VALID=1，版本57，24.6℃、346208mm/s；所有采集端口关闭 |

手动阶段捕获26条周期MANUAL记录，均与当前手动版本的温度/声速一致，未输出虚假湿度。
手动阶段DHT采样ATT和成功OK计数保持，证明自动采样暂停；AUTO恢复后重新预读，
本窗口自动成功计数新增12，周期自动OK记录65条。
